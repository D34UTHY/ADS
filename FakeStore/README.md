# 🛍️ React Fake Store App

Este projeto é uma aplicação web desenvolvida com **React** e **TypeScript**, que consome dados da [Fake Store API](https://fakestoreapi.com/) e exibe uma lista de produtos com autenticação simples por token.

## 🚀 Funcionalidades

- Login com token fake
- Visualização de lista de produtos
- Página de detalhes do produto
- Estilização com Material UI
- Navegação com React Router
- Logout

---

## 📦 Tecnologias Utilizadas

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Material UI](https://mui.com/)
- [React Router DOM](https://reactrouter.com/)
- [Axios](https://axios-http.com/) (opcional)

---
